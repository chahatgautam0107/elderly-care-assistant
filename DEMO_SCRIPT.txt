[1:00 - ARCHITECTURE]
(show assets/architecture_diagram.png)
Let's trace how a request flows through our system.
First, every query goes through the Security Checkpoint to detect prompt injections and redact PII.
Next, if safe, the request enters the Orchestrator, which coordinates the workflow and routes the queries.
The Orchestrator delegates tasks to our specialized sub-agents: the Medication Companion and the Mental Gym Companion.
These companions access local data through our dedicated MCP Server, which exposes functions like get_medications and record_wellness_check.
If a critical action is triggered—such as setting a life-critical drug or logging abnormal vitals—our system enters a Human-in-the-Loop review state, pausing for manual validation.
Finally, the Format Final Output node presents the results cleanly back to the user.
